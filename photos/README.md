# Photos des boules à neige

Une photo par boule à neige, référencée dans la colonne `photo` du Google Sheets.

## Règles de nommage

- Nom de la ville en minuscules, sans accents ni espaces : `colombo.jpg`, `santo-domingo.jpg`, `abu-dhabi.jpg`
- Plusieurs boules de la même ville : `paris-2.jpg`
- Format : `.jpg` (ou `.webp`)

## Taille

- Environ 2000 px de haut (pour pouvoir zoomer sur les détails)
- Moins de 700 Ko par photo
- JPG ou PNG (pas de HEIC : sur iPhone, Réglages → Appareil photo → Formats → « Le plus compatible »)

## Ajouter une photo

1. Sur github.com, ouvrir ce dossier `photos/`
2. **Add file → Upload files**, glisser la photo
3. **Commit changes**
4. Dans le Google Sheets, écrire le nom du fichier dans la colonne `photo`
